# scale-model-database
A full-stack database where users can search for scale models, paints and tools.

While developing the front-end, I discovered a platform called Scalemates, which is an established platform with a similar concept. Instead of abandoning this project, I decided to carry on with it to practice full-stack development and to try and make a UI with beginners in mind, allowing new model enthusiasts to find what models they would like to begin with.
